# Telegram-бот для канала @oxyAPTEM

Бот витрины проектов FlashReply и TypeRX: описания, инструкции, фишки, FAQ,
скачивание файлов прямо в боте, жёсткая проверка подписки и админ-панель с рассылкой.

## Установка

1. Получи токен у @BotFather: `/newbot` → имя → username → скопируй токен.
2. Установи Python 3.10+ и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Открой `config.py` и заполни:
   - `BOT_TOKEN` - токен от BotFather
   - `ADMIN_ID` - твой Telegram ID (узнать у @userinfobot)
4. Запусти:
   ```bash
   python bot.py
   ```

## Как добавить файлы проектов для скачивания

1. Запусти бота.
2. Отправь ему файл (zip/exe) личным сообщением **с аккаунта админа**.
3. Бот ответит `file_id` - вставь его в `config.py` → `FILES`.
4. Перезапусти бота.

## Как работает подписка

Жёсткая проверка: без подписки на @oxyAPTEM кнопки меню не работают -
бот показывает экран с кнопкой «Подписаться» и «Проверить подписку».

## Админ-панель

Команда `/admin` (только для ADMIN_ID):
- показывает число пользователей;
- кнопка «📣 Уведомить пользователей» → отправь текст → уйдёт всем, кто запускал бота.

Отмена рассылки на этапе ввода: `/cancel`.

## Где редактировать контент

Весь текст - в `texts.py`:
- описания проектов, гайды, фишки, FAQ;
- `changelog` каждого проекта - история версий.

## Постоянная работа

Чтобы бот не выключался вместе с терминалом:
- VPS: `nohup python bot.py &`
- или Railway / любой хостинг с Python.


## Render Web Service

Бот работает через webhook, поэтому на Render выбирай **Web Service**, а не Background Worker.

Настройки: 
- Runtime: Python 3
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Health Check Path: `/` (необязательно)

Render автоматически создаёт `PORT` и `RENDER_EXTERNAL_URL`. Их вручную добавлять не нужно.
URL должен быть HTTPS. После первого деплоя бот сам установит webhook Telegram.

Важно: один токен Telegram нельзя одновременно запускать через polling на компьютере и webhook на Render. Останови локальный бот перед деплоем.
